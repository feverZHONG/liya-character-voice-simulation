# 一次完整推演实录（匿名示例 · 2026-09-11）

> 首次落地：官方生日寄语太薄，想知道「此时此刻的她还会说什么」。
> **产物本体**：落作品库创作区（正文 ＋ 逐句出处 ＋ 自标填充）——本档只记配方与验收，不复制产物。

## 参数

| 项 | 值 |
|:--|:--|
| 队数 | 2（并行） |
| 角度 | ① 生日这天她还会说出口的话（4~6 句）　② 她没写在那张贺图上的那层（3~4 句） |
| 耗时 | 60~80 秒（每队 5~9 次 API 调用） |
| 喂料 | 绝对路径 8 处：官方设定档、个人整理稿、生日内容登记、故事正文 01~06（含整理稿）、设定集速查三件、关系网络 |
| 声线锚 | 官方寄语原文**原样贴**进 context（不让分队自己摘要） |

## 验收结论

- **逐句出处全部可核、抽查无编造**；意象全落在档案内（宠物掉毛 / 窗棂画花 / 洪水 / 配角名 / 绣花裙 / 道具失效 / 「这也是人间吗」这类原文意象）。
- **亮点**：末句回扣第 05 章凌晨许愿那段原文——**档案细节被真正用上了**，不是泛泛的角色腔。
- **自标填充诚实**：挑花、「价钱」这类概括词、把设定台词化，都主动标了。
- **弱项**：写得出声线，写不出「她今天想说什么」——**这是推演的天花板，不是配方问题**。

## 换锚前后对照（同一问题、两种锚料）

同一个问题问两遍，只换声线锚（官方第三人称叙述 → 她自己的原话），产出差别全在节奏：

| 指标 | 叙述锚（旧稿） | 真锚（原话） |
|:--|:--|:--|
| 省略号 | 0 次 | 11 次 |
| 「呵呵」这类口头语 | 1 次 | 3 次 |

结论：**有真原话却仍拿叙述稿当锚＝白攒**——叙述稿写的是「别人怎么讲她」，真原话才是「她怎么开口」。

## 复用要点

- **隐含前提**：本次问法写得准，是因为派活前主会话**已通读档案**（含末章与金句集）——不是运气，是先读过的结果。换成没读过档案的人派活，同样配方只会收回泛答案。
- 一队一问，宁多派队，别贪多。
- 声线锚（官方原文）必须原样贴。
- **末章正文 ＋ 名场面金句集**是声线密度最高的两处，别省。
- 产物先定落点再开跑：官方层一字不动，落作品库演绎层。
